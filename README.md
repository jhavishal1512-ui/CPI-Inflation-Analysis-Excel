# 📊 CPI Inflation Analysis Dashboard (Excel)

## 📌 Project Overview

This project analyzes India's Consumer Price Index (CPI) Inflation data from 2013 to 2023 using Microsoft Excel. The dashboard provides insights into inflation trends across Rural, Urban, and Rural+Urban sectors and identifies the major factors driving inflation.

---

## 🎯 Business Objective

The goal of this project is to:

- Analyze historical CPI inflation trends.
- Compare Rural, Urban, and Rural+Urban inflation patterns.
- Identify key contributors to inflation.
- Study the impact of major global events on inflation.
- Measure the relationship between crude oil prices and CPI inflation.
- Build an interactive dashboard for quick decision-making.

---

## 🛠 Tools & Techniques Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design
- Data Cleaning
- Data Transformation
- Trend Analysis
- Contribution Analysis
- Correlation Analysis
- Data Visualization

## 📈 Analysis Performed

### 1. CPI Trend Analysis
- Analyzed CPI movement from 2013 to 2023.
- Compared inflation trends across Rural, Urban, and Rural+Urban sectors.
- Identified long-term inflation growth patterns.

### 2. Inflation Contribution Analysis
- Categorized expenditure groups into:
  - Food
